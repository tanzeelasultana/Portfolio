# Tanzeela Sultana: Portfolio (React + Vite + Tailwind CSS)

    npm install
    npm run dev      # open the URL shown (usually http://localhost:5173)
    npm run build    # production build into /dist

- Edit all content in `src/data.js`.
- Put your resume at `public/resume.pdf`.
- The contact form is frontend-only; connect EmailJS/Formspree to make it send mail.
